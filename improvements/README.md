# Improvements

This folder keeps the current benchmark and evaluation artifacts that scripts write by default.

It is an operational surface, not a research dump.

Keep in root:
1. active `latest` reports
2. active `baseline` reports
3. reports used directly by scripts and docs

Current root reports are intentionally small and operational.

Rules:
1. root files should be either `*-baseline.*` or `*-latest.*`
2. root files may also include a very small number of actively referenced closure reports
3. provider-specific experiments, cache-check runs, one-off competitive captures, old waves, empirical captures, and superseded notes are removed from the active tree
4. scripts should default to root paths only when the artifact is part of the active working surface

## Freshness review (2026-11-15, v0.1.52)

A `latest` suffix is a filename convention, not a freshness guarantee. Check
`generated_at_utc` before citing a report as evidence for the current release.
No tracked report in this directory was generated by v0.1.52; the newest
tracked operational report is `discovery-eval-latest.json` (generated
2026-09-18). The other tracked reports were generated between 2026-03-28 and
2026-05-07 and are retained as baselines, reproduction evidence, or historical
closures. The October claim/decision captures are analysis-only and are not

### Maintenance rule

Before replacing a baseline, record why the old measurement is no longer the
comparison point. Before deleting a one-off report, check whether it is cited
by docs, a benchmark runner, or an open issue. A report that is stale but still
cited is a documentation problem before it is a storage problem.
