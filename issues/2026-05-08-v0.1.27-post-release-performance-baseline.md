## Devil's Advocate

The headline memory result is strong, but it can be misrepresented if reported carelessly.

Risks:

1. The 96% warm pass rate depends on a prior successful read/indexing step.
2. Cold seedless remains weak on the 100-case corpus at 15% selected pass.
3. Browser-like live discovery improves specific cases but is too timeout-prone as primary path.
4. Home/about/overview intent is still not precise enough inside the semantic family.
5. Current benchmark runners do not test the installed binary directly.

These do not invalidate the semantic architecture. They define the next quality frontier.

## Recommended Next Macrostep

Primary target: semantic cold bootstrap and entity-home recovery.

Concrete work:

1. Add a semantic bootstrap memory seeding phase that uses prior entity/family observations before public provider ranking.
2. Add an embeddings-first home/about/overview intent resolver that distinguishes canonical home, about page, docs root, tutorial, manual, API reference, and deep solution pages without lexical term rules.
3. Add installed-binary benchmark mode so release validation measures the exact public artifact.
4. Add a cache ROI benchmark that exercises repeated embedding requests without `--force-embeddings`.
5. Add browser-like budget governance: use it as targeted fallback, not default primary, unless health memory predicts it is necessary.

Success thresholds for the next performance step:

- Discovery Memory warm pass: keep >= 96% on 100 cases.
- Multilingual warm pass: keep 13/13 or expand and keep >= 95%.
- Cold selected pass: raise from 15% to at least 35% without lexical heuristics.
- Browser-like timeout rate: reduce from 25% to below 10% on the 8-case live corpus.
- Home/about/overview warm failures: reduce from 4 to <= 1 on the 100-case corpus.

## Implementation Update: Semantic Entity-Home Recovery

Implemented after this baseline:

1. `DiscoverWeb` now runs target-kind reranking in the web discovery finalization path.
2. Target-kind inference now uses multiple embedding prototypes per page intent instead of one long abstract archetype.
3. Canonical-home inference is allowed to win when it is semantically close to a competing intent and has sufficient embedding similarity.
4. Memory family recovery now infers target-kind before same-site probing consumes semantic timeout budget.
5. Root memory seeds no longer always degrade into the deepest same-site link; canonical-home intent preserves the root, while non-home intents can still recover specific child pages.
